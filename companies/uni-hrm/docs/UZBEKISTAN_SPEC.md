## 1. ПИНФЛ (Персональный идентификационный номер физического лица)

### Общие сведения

ПИНФЛ — уникальный 14-значный идентификатор, присваиваемый каждому физическому лицу в Республике Узбекистан.
Является основным идентификатором в государственных информационных системах.

- **Длина:** 14 цифр
- **Присваивается:** при рождении или при получении гражданства
- **Уникальность:** гарантируется на уровне государства
- **Обязательность:** для всех трудовых отношений

### Структура ПИНФЛ

```
Г Г Г Г  М М  Д Д  Н  Р Р Р  К К
│ │ │ │  │ │  │ │  │  │ │ │  │ │
│ │ │ │  │ │  │ │  │  │ │ │  └─┘── Контрольная сумма (2 цифры)
│ │ │ │  │ │  │ │  │  └─┴─┘────── Код региона (3 цифры)
│ │ │ │  │ │  │ │  └──────────── Пол и век рождения (1 цифра)
│ │ │ │  │ │  └─┘─────────────── День рождения (2 цифры, 01-31)
│ │ │ │  └─┘───────────────────── Месяц рождения (2 цифры, 01-12)
└─┴─┴─┘───────────────────────── Год рождения (4 цифры)
```

### Алгоритм валидации ПИНФЛ (пошагово)

**Шаг 1.** Проверить, что строка содержит ровно 14 цифр.

**Шаг 2.** Извлечь компоненты:
- `year = ПИНФЛ[0:4]` — год рождения
- `month = ПИНФЛ[4:6]` — месяц рождения
- `day = ПИНФЛ[6:8]` — день рождения
- `gender_century = ПИНФЛ[8]` — пол и век
- `region = ПИНФЛ[9:12]` — код региона
- `checksum = ПИНФЛ[12:14]` — контрольная сумма

**Шаг 3.** Проверить дату рождения:
- Месяц: 01 <= month <= 12
- День: 01 <= day <= 31 (с учётом месяца и високосного года)
- Год: корректный год в соответствии с `gender_century`

**Шаг 4.** Проверить код пола и века:
- Значение должно быть от 1 до 6
- Должно быть согласовано с годом рождения (например, для `gender_century=3` или `4` год должен быть 1900-1999)

**Шаг 5.** Проверить код региона:
- Значение должно быть в допустимом диапазоне (001-799)

**Шаг 6.** Вычислить контрольную сумму:
- Взять первые 12 цифр ПИНФЛ
- Умножить каждую цифру на соответствующий весовой коэффициент из массива `[7, 3, 1, 7, 3, 1, 7, 3, 1, 7, 3, 1]`
- Сложить все произведения
- Результат `mod 100` должен равняться значению `checksum`

> **Примечание:** Точный алгоритм контрольной суммы не опубликован официально. Приведённый выше алгоритм
> является наиболее распространённой версией. В production-системе рекомендуется верифицировать ПИНФЛ
> через API государственных сервисов (my.gov.uz).

### Django Validator

```python
import re
from datetime import date

from django.core.exceptions import ValidationError
from django.utils.translation import gettext_lazy as _


def validate_pinfl(value: str) -> None:
    """
    Валидатор ПИНФЛ (Персональный идентификационный номер физического лица).

    Проверяет:
    - Длину (14 цифр)
    - Формат (только цифры)
    - Корректность даты рождения
    - Корректность кода пола/века
    - Контрольную сумму
    """
    if not re.match(r"^\d{14}$", value):
        raise ValidationError(
            _("ПИНФЛ должен содержать ровно 14 цифр."),
            code="invalid_pinfl_format",
        )

    year = int(value[0:4])
    month = int(value[4:6])
    day = int(value[6:8])
    gender_century = int(value[8])
    region = int(value[9:12])
    checksum = int(value[12:14])

    # Проверка кода пола и века
    if gender_century not in range(1, 7):
        raise ValidationError(
            _("Некорректный код пола и века в ПИНФЛ."),
            code="invalid_pinfl_gender",
        )

    # Проверка соответствия века и года
    century_map = {1: (1800, 1899), 2: (1800, 1899),
                   3: (1900, 1999), 4: (1900, 1999),
                   5: (2000, 2099), 6: (2000, 2099)}
    min_year, max_year = century_map[gender_century]
    if not (min_year <= year <= max_year):
        raise ValidationError(
            _("Год рождения не соответствует коду века в ПИНФЛ."),
            code="invalid_pinfl_year",
        )

    # Проверка даты рождения
    try:
        birth_date = date(year, month, day)
        if birth_date > date.today():
            raise ValidationError(
                _("Дата рождения в ПИНФЛ не может быть в будущем."),
                code="invalid_pinfl_future_date",
            )
    except ValueError:
        raise ValidationError(
            _("Некорректная дата рождения в ПИНФЛ."),
            code="invalid_pinfl_date",
        )

    # Проверка кода региона
    if not (1 <= region <= 799):
        raise ValidationError(
            _("Некорректный код региона в ПИНФЛ."),
            code="invalid_pinfl_region",
        )

    # Проверка контрольной суммы
    weights = [7, 3, 1, 7, 3, 1, 7, 3, 1, 7, 3, 1]
    digits = [int(d) for d in value[:12]]
    calculated_checksum = sum(d * w for d, w in zip(digits, weights)) % 100

    if calculated_checksum != checksum:
        raise ValidationError(
            _("Некорректная контрольная сумма ПИНФЛ."),
            code="invalid_pinfl_checksum",
        )


# Использование в модели
from django.db import models


class Employee(models.Model):
    pinfl = models.CharField(
        max_length=14,
        unique=True,
        validators=[validate_pinfl],
        verbose_name=_("ПИНФЛ"),
        help_text=_("Персональный идентификационный номер физического лица (14 цифр)"),
    )
```

### Утилита извлечения данных из ПИНФЛ

```python
from dataclasses import dataclass
from datetime import date


@dataclass
class PINFLData:
    """Данные, извлечённые из ПИНФЛ."""
    birth_date: date
    gender: str  # "male" | "female"
    region_code: int
    century: int


def parse_pinfl(pinfl: str) -> PINFLData:
    """Извлечь структурированные данные из ПИНФЛ."""
    year = int(pinfl[0:4])
    month = int(pinfl[4:6])
    day = int(pinfl[6:8])
    gender_century = int(pinfl[8])
    region = int(pinfl[9:12])

    gender = "male" if gender_century % 2 == 1 else "female"
    century = {1: 19, 2: 19, 3: 20, 4: 20, 5: 21, 6: 21}[gender_century]

    return PINFLData(
        birth_date=date(year, month, day),
        gender=gender,
        region_code=region,
        century=century,
    )
```

## 2. ИНН (Идентификационный номер налогоплательщика)

### Общие сведения

- **Длина:** 9 цифр для физических лиц
- **Присваивается:** налоговыми органами при постановке на учёт
- **Уникальность:** гарантируется на уровне государства
- **Обязательность:** для всех трудовых отношений и налоговых операций

### Структура ИНН (физическое лицо)

```
Р Р  Н Н Н Н Н  К К
│ │  │ │ │ │ │  │ │
│ │  │ │ │ │ │  └─┘── Контрольные цифры (2 цифры)
│ │  └─┴─┴─┴─┘────── Порядковый номер (5 цифр)
└─┘───────────────── Код налогового органа (2 цифры)
```

### Django Validator

```python
import re

from django.core.exceptions import ValidationError
from django.utils.translation import gettext_lazy as _


def validate_inn(value: str) -> None:
    """
    Валидатор ИНН (Идентификационный номер налогоплательщика) для физических лиц.

    Проверяет:
    - Длину (9 цифр)
    - Формат (только цифры)
    - Контрольную сумму (если алгоритм известен)
    """
    if not re.match(r"^\d{9}$", value):
        raise ValidationError(
            _("ИНН должен содержать ровно 9 цифр."),
            code="invalid_inn_format",
        )

    # Проверка, что не состоит из одинаковых цифр
    if len(set(value)) == 1:
        raise ValidationError(
            _("ИНН не может состоять из одинаковых цифр."),
            code="invalid_inn_pattern",
        )

    # Контрольная сумма (алгоритм для ИНН Узбекистана)
    # Весовые коэффициенты для проверки
    weights = [1, 3, 7, 1, 3, 7, 1]
    digits = [int(d) for d in value]

    # Вычисление контрольного разряда
    checksum = sum(d * w for d, w in zip(digits[:7], weights)) % 10

    # Примечание: точный алгоритм может отличаться.
    # В production рекомендуется верифицировать через API ГНК.


# Использование в модели
from django.db import models


class Employee(models.Model):
    inn = models.CharField(
        max_length=9,
        unique=True,
        validators=[validate_inn],
        verbose_name=_("ИНН"),
        help_text=_("Идентификационный номер налогоплательщика (9 цифр)"),
    )
```

### Связь ПИНФЛ и ИНН

В системе HRM оба идентификатора являются обязательными:

| Поле  | Назначение                          | Где используется                       |
|-------|-------------------------------------|----------------------------------------|
| ПИНФЛ | Идентификация личности              | Кадровый учёт, HEMIS, госсервисы       |
| ИНН   | Налоговая идентификация             | Расчёт зарплаты, налоговая отчётность  |

## 3. Трудовое законодательство Узбекистана

> Основание: Трудовой кодекс Республики Узбекистан (новая редакция, вступил в силу 30.04.2023)

### 3.1. Виды трудовых договоров

#### Бессрочный трудовой договор

- **Описание:** Заключается на неопределённый срок
- **Применение:** Основной вид для постоянных сотрудников университета
- **Особенности:**
  - Может быть расторгнут по инициативе работника с уведомлением за 14 календарных дней
  - Расторжение по инициативе работодателя — только по основаниям, предусмотренным ТК

#### Срочный трудовой договор

- **Описание:** Заключается на определённый срок, но не более 5 лет
- **Применение:** ППС (профессорско-преподавательский состав) по конкурсу, замещение временно отсутствующего работника
- **Особенности:**
  - Максимальный срок — 5 лет
  - По истечении срока: прекращается автоматически, если ни одна из сторон не заявила о расторжении
  - Для ППС — связан с результатами конкурса на замещение должности (каждые 5 лет)
  - При повторном заключении более 2 раз подряд — может быть признан бессрочным

#### На время выполнения определённой работы

- **Описание:** Заключается для выполнения конкретной работы, завершение которой определяет срок договора
- **Применение:** Проектная работа, грантовые исследования, строительные/ремонтные работы
- **Особенности:**
  - Прекращается по завершении работы
  - Работник не может быть уволен до завершения работы без оснований

#### Совместительство

**Внутреннее совместительство:**
- Работа у того же работодателя по другой должности в свободное от основной работы время
- Пример: преподаватель кафедры математики ведёт занятия на кафедре информатики
- Оплата: пропорционально отработанному времени

**Внешнее совместительство:**
- Работа у другого работодателя в свободное от основной работы время
- Ограничение: не более 0.5 ставки
- Требует уведомления основного работодателя (для госслужащих — разрешения)

#### Почасовой трудовой договор

- **Описание:** Оплата исключительно за фактически отработанные часы
- **Применение:** Приглашённые лекторы, преподаватели-практики из индустрии
- **Особенности:**
  - Оплата по утверждённым тарифам ВУЗа
  - Не предусматривает отпуск и больничные (если менее установленного порога часов)
  - Часто используется для привлечения специалистов-практиков

### 3.2. Испытательный срок

| Параметр                          | Значение                          |
|-----------------------------------|-----------------------------------|
| Максимальная длительность         | 3 месяца                          |
| Для руководителей и заместителей  | до 6 месяцев                      |
| Оформление                       | Обязательно указывается в договоре |
| Увольнение в период испытания     | С уведомлением за 3 дня           |

| Категория                         | Норма часов/неделю |
|-----------------------------------|--------------------|
| Стандартная                       | 40 часов           |
| Вредные/опасные условия           | 36 часов           |
| Работники 16-18 лет              | 36 часов           |
| Работники до 16 лет              | 24 часа            |
| Инвалиды I и II группы           | 36 часов           |

**Нормы для ППС университета:**
- Максимальная учебная нагрузка: 900 часов в учебном году
- Включает: лекции, практические, лабораторные, консультации, экзамены
- Остальное время: научная работа, методическая работа, воспитательная работа

### 3.4. Отпуска

#### Основной ежегодный отпуск

| Категория сотрудника                | Продолжительность           |
|-------------------------------------|-----------------------------|
| Общий минимум                       | 15 рабочих дней             |
| Административно-управленческий персонал (АУП) | 24 календарных дня |
| ППС ВУЗов (летний каникулярный)    | 56 календарных дней         |
| Научные работники (доктора наук)    | 48 календарных дней         |
| Научные работники (кандидаты наук, PhD) | 36 календарных дней     |

> **Важно для системы:** Отпуск ППС привязан к учебному календарю. Летний каникулярный период
> обычно с 1 июля по 25 августа. Система должна учитывать учебный календарь при планировании отпусков.

#### Дополнительные отпуска

| Вид отпуска                        | Продолжительность           | Условия                     |

| За ненормированный рабочий день     | до 7 календарных дней       | Перечень должностей в ЛНА   |
| За стаж работы                      | до 12 календарных дней      | Определяется ЛНА            |
| За особый характер работы           | до 14 календарных дней      | Перечень должностей в ЛНА   |

#### Учебный отпуск

| Основание                           | Продолжительность           | Оплата     |
|-------------------------------------|-----------------------------|------------|
| Сдача вступительных экзаменов       | 15 календарных дней         | Без оплаты |
| Сессия (заочное обучение)           | 30-40 календарных дней/год  | С оплатой  |
| Подготовка и защита диссертации (PhD)| до 6 месяцев               | С оплатой  |
| Подготовка и защита диссертации (DSc)| до 12 месяцев              | С оплатой  |

#### Отпуск без сохранения заработной платы

- По семейным обстоятельствам и другим уважительным причинам
- Продолжительность — по соглашению сторон
- Инициатива работника, работодатель не может принуждать
- В системе: отдельный тип заявки с указанием причины

#### Социальные отпуска

| Вид                                 | Продолжительность           |
|-------------------------------------|-----------------------------|
| Отпуск по беременности и родам      | 70 + 56 дней (нормальные роды), 70 + 70 (осложнённые) |
| Отпуск по уходу за ребёнком         | До достижения 2 лет         |
| Дополнительный (до 3 лет ребёнка)   | Без сохранения зарплаты     |

### 3.5. Больничные листы

- **Оплата:** за счёт средств работодателя (ФОТ)
- **Размер:** зависит от стажа работы:

| Стаж работы         | Размер пособия (% от среднего заработка) |
|---------------------|------------------------------------------|
| До 5 лет            | 60%                                      |
| 5-8 лет             | 80%                                      |
| Свыше 8 лет         | 100%                                     |

- **Максимальная длительность:** до 120 дней непрерывно, далее — ВТЭК
- **Документ:** электронный больничный лист (внедряется с 2024)

## 4. Налоги и отчисления (2024-2025)

### 4.1. Налоги с доходов физических лиц

| Вид налога/отчисления               | Ставка  | Плательщик    | Примечание                    |
|--------------------------------------|---------|---------------|-------------------------------|
| НДФЛ                                | 12%     | Работник      | Единая ставка, удерживается работодателем |
| Социальный налог                     | 12%     | Работодатель  | От ФОТ, в бюджет              |
| ИНПС (накопительная пенсия)         | 0.1%    | Работодатель  | Индивидуальный накопительный пенсионный счёт |

### 4.2. НДФЛ (Налог на доходы физических лиц)

- **Ставка:** 12% (единая плоская шкала с 2019 года)
- **Налоговая база:** все доходы в денежной и натуральной форме
- **Вычеты:**
  - Необлагаемый минимум: 1 МРЗП в месяц (для определённых категорий)
  - На каждого ребёнка до 18 лет: дополнительные вычеты
  - Инвалиды I и II группы: дополнительные льготы
- **Расчёт в системе:**

```python
from decimal import Decimal


def calculate_ndfl(
    gross_salary: Decimal,
    tax_deductions: Decimal = Decimal("0"),
) -> Decimal:
    """
    Расчёт НДФЛ.

    Args:
        gross_salary: Начисленная зарплата (до вычетов)
        tax_deductions: Сумма налоговых вычетов

    Returns:
        Сумма НДФЛ к удержанию
    """
    NDFL_RATE = Decimal("0.12")
    taxable_income = max(gross_salary - tax_deductions, Decimal("0"))
    return (taxable_income * NDFL_RATE).quantize(Decimal("1"))
```

### 4.3. Социальный налог

- **Ставка:** 12% от ФОТ
- **Плательщик:** работодатель (не удерживается из зарплаты работника)
- **Назначение:** финансирование социальных программ, пенсионный фонд
- **Особенности для бюджетных организаций (ВУЗы):**
  - ВУЗы как бюджетные организации могут иметь льготные ставки
  - Необходимо учитывать источник финансирования (бюджет / внебюджет / гранты)

### 4.4. ИНПС (Индивидуальный накопительный пенсионный счёт)

- **Обязательные отчисления работодателя:** 0.1% от ФОТ
- **Добровольные взносы работника:** от 1% до 7% (по заявлению)
- **Управление:** Народный банк или другие уполномоченные организации
- **В системе:** необходимо отслеживать:
  - Обязательные отчисления (автоматически)
  - Добровольные взносы (по заявлению сотрудника)
  - Историю изменений размера добровольных взносов

### 4.5. Формула расчёта зарплаты

```
Начисления:
  + Оклад (ставка × коэффициент)
  + Надбавка за учёную степень
  + Надбавка за учёное звание
  + Надбавка за стаж
  + Надбавка за вредные условия
  + Премии
  + Совместительство
  + Почасовая оплата
  = Итого начислено (gross)

Удержания:
  - НДФЛ: (gross - вычеты) × 12%
  - ИНПС (добровольные): gross × (1-7%)
  - Профсоюзные взносы: gross × 1% (при членстве)
  - Алименты (при наличии исп. листа)
  - Прочие удержания (не более 50% от зарплаты)
  = Итого удержано

К выплате (net):
  = Итого начислено - Итого удержано

Начисления работодателя (сверх ФОТ):
  + Социальный налог: gross × 12%
  + ИНПС (обязательные): gross × 0.1%
```

### 4.6. МРЗП и базовые расчётные величины

| Показатель | Значение (2025) | Примечание |
|------------|-----------------|------------|
| МРЗП       | 1 155 000 сум   | Минимальный размер заработной платы |
| БРВ        | 340 000 сум     | Базовая расчётная величина |

> **Важно:** Значения МРЗП и БРВ обновляются ежегодно. Система должна хранить исторические
> значения и позволять администратору обновлять текущие.

## 7. Учёные степени и звания

### 7.1. Учёные степени

| Степень | Аббревиатура | На узбекском        | Описание                                |
|---------|-------------|----------------------|-----------------------------------------|
| PhD     | PhD         | Falsafa doktori (fal.fan.dok.) | Доктор философии по специальности |
| DSc     | DSc         | Fan doktori (fan dok.) | Доктор наук по специальности        |

**Процедура получения PhD:**
1. Поступление в базовую докторантуру (3 года) или самостоятельное прикрепление (соискательство)
2. Выполнение научного исследования
3. Публикация минимум 5 научных статей (из них 2 — в зарубежных журналах)
4. Защита диссертации перед Научным советом при ВУЗе
5. Утверждение ВАК при Кабинете Министров РУз
6. Выдача диплома

**Процедура получения DSc:**
1. Наличие степени PhD (обязательно)
2. Поступление в докторантуру (DSc) на 3 года или самостоятельная подготовка
3. Публикация минимум 10 научных статей (из них 5 — в зарубежных журналах с импакт-фактором)
4. Наличие монографии
5. Защита диссертации перед Научным советом
6. Утверждение ВАК при Кабинете Министров РУз
7. Выдача диплома

### 7.2. Учёные звания

| Звание     | Требования                                                                    |
|------------|-------------------------------------------------------------------------------|
| Доцент     | Степень PhD + 5 лет педагогического стажа + опубликованные учебные пособия    |
| Профессор  | Степень DSc + 10 лет стажа + подготовка PhD-докторантов + монографии/учебники |

**Процедура присвоения учёного звания:**
1. Представление документов кафедрой → Учёный совет факультета
2. Рассмотрение Учёным советом ВУЗа → Рекомендация
3. Направление документов в ВАК при Кабинете Министров
4. Рассмотрение ВАК → Присвоение звания
5. Выдача аттестата

## 10. Валюта и форматы

### 10.1. Валюта

| Параметр       | Значение                    |
|----------------|-----------------------------|
| Код валюты     | UZS                         |
| Название       | Узбекский сум               |
| Символ         | сум (или so'm)              |
| Дробная часть  | тийин (1 сум = 100 тийин), практически не используется |

### 10.2. Форматирование чисел

| Формат          | Пример                      | Описание                    |
|-----------------|-----------------------------|-----------------------------|
| Целое число     | `1 000 000`                 | Пробел как разделитель тысяч |
| Денежная сумма  | `5 500 000 сум`             | Число + единица валюты      |
| Десятичное      | `1 234,56`                  | Запятая как десятичный разделитель |
| Процент         | `12%` или `12,5%`           | Без пробела перед %         |

### 10.3. Форматирование дат

| Формат             | Пример          | Использование                 |
|--------------------|-----------------|-------------------------------|
| Полный             | `15.03.2025`    | Официальные документы         |
| Сокращённый        | `15.03.25`      | Неформальное использование    |
| ISO 8601           | `2025-03-15`    | API, база данных              |
| Текстовый          | `15 марта 2025 г.` | Приказы, письма            |

### 10.4. Форматирование в Django

```python
# settings.py
LANGUAGE_CODE = "ru"
TIME_ZONE = "Asia/Tashkent"  # UTC+5
USE_I18N = True
USE_L10N = True
USE_TZ = True

# Формат дат для русской локали
DATE_FORMAT = "d.m.Y"
DATETIME_FORMAT = "d.m.Y H:i"
SHORT_DATE_FORMAT = "d.m.Y"

# Формат чисел
DECIMAL_SEPARATOR = ","
THOUSAND_SEPARATOR = " "
USE_THOUSAND_SEPARATOR = True
NUMBER_GROUPING = 3
```

### 10.5. Телефонные номера

| Параметр       | Значение                    |
|----------------|-----------------------------|
| Код страны     | +998                        |
| Формат         | +998 (XX) XXX-XX-XX         |
| Мобильные коды | 90, 91, 93, 94, 95, 97, 98, 99, 33, 50, 55, 77, 88 |
| Городские коды | 71 (Ташкент), 62, 65, 66, 67, 69, 73, 75, 76, 79 |

```python
import re
from django.core.exceptions import ValidationError
from django.utils.translation import gettext_lazy as _


def validate_uzbekistan_phone(value: str) -> None:
    """Валидатор номера телефона Узбекистана."""
    pattern = r"^\+998\d{9}$"
    if not re.match(pattern, value):
        raise ValidationError(
            _("Номер телефона должен быть в формате +998XXXXXXXXX"),
            code="invalid_phone",
        )
```

### 10.6. Локализация интерфейса

Система должна поддерживать три языка:

| Язык       | Код  | Использование                         |
|------------|------|---------------------------------------|
| Русский    | `ru` | Основной язык интерфейса и документов |
| Узбекский  | `uz` | Государственный язык, официальные документы |
| Английский | `en` | Международное сотрудничество          |

```python
# settings.py
LANGUAGES = [
    ("ru", _("Русский")),
    ("uz", _("O'zbek")),
    ("en", _("English")),
]
```
